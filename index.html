How it works

Three steps. No account, no backend.

  1. github.com/vitejs/vite
    01

    Paste a repository

    One call to the GitHub tree API returns every path and size. A few commit lookups add recent activity.

  2. 02

    We map it

    A squarified treemap nests folders into districts. Import statements are parsed from source files into dependency roads.

  3. 03

    Explore it

    Orbit, zoom and fly between districts. Hold a building to open its details and jump straight to the file on GitHub.

Features

Built to be explored, not just looked at.

Treemap districts

Folders nest into neighbourhoods using a squarified layout, so large areas stay readable.

Churn heatmap

Colour follows how often a file changed across the last 30 commits.

Dependency roads

Animated arcs show what a building imports and who imports it, only for what you point at.

Hold to open

A progress ring fills around your finger or cursor; a haptic tick confirms the long-press.

⌘Kconfig

Instant search

Press ⌘K to find any file or folder and fly the camera straight to it.

Private by design

Everything runs client-side. Responses are cached in your browser; an optional token never leaves it.
